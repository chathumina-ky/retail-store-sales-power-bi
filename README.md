# Retail Store Sales Analysis – Power BI

A Power BI project exploring and analyzing retail store sales data.

## Dataset

“Retail Store Sales: Dirty for Data Cleaning” by Ahmed Mohamed, downloaded from [Kaggle](https://www.kaggle.com/datasets/ahmedmohamed2003/retail-store-sales-dirty-for-data-cleaning).

The dataset is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The data has been cleaned or adapted for this project.
